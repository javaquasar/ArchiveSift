Static Demo Target

ArchiveSift Demo Site

This mini static website exists as a safe public scraping target for demo scrapers, parser tests, fixture generation, and GitHub Pages hosting.

Open channel listing Open lazy-load listing Open model listing Open gallery page Open random showcase

What This Covers

  • Gallery pages with title, metadata, and image entries
  • Listing pages that link to galleries and next pages
  • Lazy-loaded listings backed by JSON payloads
  • Actor/model style discovery pages
  • Stable CSS selectors for parser regression tests

Why It Helps

  • No dependency on a third-party site
  • Safe to publish publicly on GitHub Pages
  • Easy to version when scraper contracts change
  • Useful as a demo for multiple supported scrapers

Suggested Parser Hooks

  • [data-demo-role="listing"]
  • .demo-gallery-link
  • .demo-next-page
  • [data-demo-role="gallery"]
  • [data-demo-full]
